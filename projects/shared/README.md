# Shared Data Layer & Schemas (`projects/shared/`)

Contains shared data contracts, sample fixtures, and persistent storage modules used by both the **Seller Agent** and **Buyer Agent**.

## Files
- [`sample_catalog.json`](sample_catalog.json): 3-SKU sample product catalog (`SKU-100`, `SKU-101`, `SKU-102`) used in Sprint 1 to reduce task-to-task dependencies while the full `ProductCatalog` loader is under development.
