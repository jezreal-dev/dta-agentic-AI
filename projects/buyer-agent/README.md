# eComMART Buyer Agent (`projects/buyer-agent/`)

The **Buyer Agent** acts as a procurement assistant for B2B buyers on eComMART.

## Responsibilities & Epics
- **Epic E3 (`FR-07`, `FR-08`, `NFR-05`):**
  - **Story 3.1:** Allow buyers to submit a Request for Quotation (RFQ) in a single step (`NFR-05`).
  - **Story 3.2:** Allow buyers to check real-time RFQ status without chasing suppliers (`< 5 s` latency in 95% of 20 test runs).
