## Overview of the 12 Week 3 Exercises

All exercises use the **eCOMMart** B2B marketplace context and progress from foundational syntax to full agent-tool patterns:

| # | Exercise | Core Python Topics | Difficulty | Est. Time |
| :---: | :--- | :--- | :---: | :---: |
| **1** | **Product Label with All Three String Types** | Variables, single/double/triple quotes, f-strings | 🟢 Beginner | 10 min |
| **2** | **Price Calculator for 5 Items** | Arithmetic operators, floats, rounding | 🟢 Beginner | 10 min |
| **3** | **Membership Tier Checker** | `if / elif / else`, boolean flags, `input()` | 🟢 Beginner | 10 min |
| **4** | **Product Catalog Dictionary** | `dict`, `.get()`, loop iteration | 🟢 Beginner | 15 min |
| **5** | **Tuple + Set Operations** | `tuple` immutability, `set` union/intersection/difference | 🟡 Intermediate | 15 min |
| **6** | **Smart Discount Engine** | Functions, `is_nan()`, `safe_eval_price()` | 🟡 Intermediate | 20 min |
| **7** | **Shopping Cart System** | Functions, lists of dicts, `while` loop | 🟡 Intermediate | 20 min |
| **8** | **Delivery Zone Checker** | Function docstrings, dictionary lookup, string slicing | 🟡 Intermediate | 15 min |
| **9** | **Product Validator (Agent Tool Pattern)** | Structured dict return contracts, multi-rule validation | 🔴 Advanced | 25 min |
| **10** | **List Comprehension Analytics** | List comprehensions with filtering and mapping | 🔴 Advanced | 20 min |
| **11** | **Exception Handling: Safe Order Processor** | `try / except / finally`, `raise ValueError`, `KeyError` | 🔴 Advanced | 20 min |
| **12** | **Capstone: eCOMMart Order Terminal** | Interactive CLI combining all Week 3 concepts | 🔴 Capstone | 40 min |
